# Invariant Enforcement Matrix

This file expands the invariant strategy from `06-invariants-and-errors.md` into a line-by-line map from every domain invariant to its primary enforcement point.

## Invariant Matrix

| Invariant | Rule                                                                                                                                                                                                                                                                                                                 | Category          | Enforced By                                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `INV-001` | Every mutable domain entity is owned by exactly one user.                                                                                                                                                                                                                                                            | Cross-cutting     | `AuthorizationScope` plus repository ownership columns on every user-owned aggregate                                     |
| `INV-002` | Cross-user reads and writes are forbidden.                                                                                                                                                                                                                                                                           | Cross-cutting     | `AuthorizationScope` middleware/decorator                                                                                |
| `INV-003` | Verified identity is required before domain mutation.                                                                                                                                                                                                                                                                | Cross-cutting     | `VerifiedIdentityGuard`                                                                                                  |

| `INV-005` | Revoked or expired sessions are unauthorized and cannot be reactivated.                                                                                                                                                                                                                                              | Cross-cutting     | auth middleware + `IAuthService.logout` / `IAuthService.expire_sessions`                                                 |

| `INV-007` | Every mutation-capable system job executes service-principal authorization validation before mutation.                                                                                                                                                                                                               | Cross-cutting     | job principal wrapper + `AuthorizationScope` job path                                                                    |
