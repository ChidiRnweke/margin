# Interaction Traceability

This file maps every interaction in `architecture/interaction-matrix.md` to its architectural entry point, owning service, repository scope, governing invariants, and primary error set.

Global mutation rules for all create/mutate interactions unless the interaction is explicitly read-only or job-only without user command idempotency:

- `SYS-01` / `INV-180..182` apply to every user-triggered create or mutate command.
- `AUD-01` / `INV-009`, `INV-170..173` apply to every successful mutation.

## Coverage Statement

- Every interaction from `architecture/interaction-matrix.md` is mapped in this file.
- Each row names the owning architectural entry point and the service that semantically owns the interaction.
- Cross-cutting interactions such as `AUD-01`, `SYS-01`, and `SYS-02` are represented as infrastructure concerns rather than controller methods because that is their correct architectural form.
